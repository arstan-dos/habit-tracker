# Rhythm — трекер привычек

Устанавливаемый PWA-трекер привычек: пользователь задаёт привычки и расписание, отмечает выполнение или осознанный пропуск, ведёт заметки и смотрит недельный и общий прогресс.

## Возможности

- полный список привычек на основной вкладке «Сегодня»: запланированные привычки получают кнопки выполнения, остальные остаются доступными для просмотра и редактирования;
- отдельный список всех привычек для управления в любой день;
- история расписаний: новое расписание применяется с текущего дня, не меняя прошлую статистику;
- недельная сетка без возможности отмечать будущие даты;
- честная статистика: запланированные дни без отметки учитываются как невыполненные;
- подразделы привычки и ежедневные заметки;
- текстовый отчёт для разбора с ИИ;
- экспорт и восстановление данных из JSON или полного текстового отчёта;
- локальная работа и установка на домашний экран.

## Данные и приватность

Данные хранятся локально в браузере, отдельно для каждого устройства и профиля. Синхронизации с сервером нет.

Отчёт содержит названия привычек, отметки и заметки. Перед отправкой отчёта стороннему ИИ или человеку проверьте его содержимое.

Для резервного копирования:

1. На вкладке «Прогресс» нажмите «Собрать отчёт».
2. Сохраните скопированный текст в файл.
3. Для восстановления выберите этот файл в разделе импорта. Поддерживается также чистый JSON состояния.

## Структура

- `index.html` — разметка приложения;
- `styles.css` — стили и адаптивная компоновка;
- `model.js` — модель данных, миграция и расчёт статистики;
- `app.js` — интерфейс и хранение;
- `sw.js` — офлайн-кэш;
- `tests/model.test.js` — тесты расчётов и миграции.

Сборка и внешние зависимости не требуются.

## Запуск

Откройте каталог через любой локальный HTTP-сервер. Service worker не работает при открытии `index.html` напрямую с диска.
