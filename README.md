# Rhythm — трекер привычек

Универсальный трекер привычек: заводишь свои привычки (название + необязательный подзаголовок + дни недели), отмечаешь день за днём — сделано / осознанный пропуск, смотришь недельную сетку, серии и общий прогресс. Работает как устанавливаемое PWA-приложение на телефоне (Add to Home Screen).

Это обобщённая версия личного трекера режима — без жёстко зашитых привычек, программ тренировок и привязки ко времени суток. Все привычки создаются пользователем при первом запуске.

## Данные
Хранятся локально в браузере (localStorage), отдельно для каждого устройства/браузера. На вкладке «Прогресс» есть кнопка «Собрать отчёт» — текстовый экспорт всех данных для бэкапа или разбора с ИИ.

## Технологии
Один статический HTML-файл, без сборки и зависимостей (кроме шрифтов Google Fonts). Манифест + service worker для установки на телефон и офлайн-работы.
